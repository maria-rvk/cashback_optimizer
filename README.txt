# Кэшбэк-оптимизатор

Веб-приложение на Flask, которое помогает выбрать банковскую карту
с максимальным кэшбэком для конкретной покупки.

## Возможности

- ведение списка банковских карт и правил кэшбэка по категориям;
- учёт трат: место, категория, сумма, дата, карта оплаты;
- редактирование и удаление трат;
- статистика: графики трат по категориям и долям карт (Matplotlib),
  таблица с разбивкой;
- советник: расчёт, какой картой выгоднее оплатить покупку,
  с полным рейтингом карт.

## Технологии

- Python 3, Flask;
- Flask-SQLAlchemy (ORM) + SQLite — база данных;
- Flask-WTF + WTForms — формы и валидация;
- Jinja2 — шаблоны с наследованием;
- Matplotlib — визуализация.

## ООП в проекте

- классы моделей `Card`, `CashbackRule`, `Transaction` наследуются
  от `db.Model` (SQLAlchemy);
- классы форм наследуются от `FlaskForm`;
- собственный класс `CashbackOptimizer` инкапсулирует логику
  расчёта кэшбэка (методы `cashback_for` и `best_card`).

## Запуск

1. Клонировать репозиторий и перейти в папку проекта.
2. Создать виртуальное окружение и установить зависимости:
	python -m venv venv venv\Scripts\activate pip install -r requirements.txt

3. Запустить сервер:
	python app.py

4. Открыть в браузере: http://127.0.0.1:5000

База данных создаётся автоматически при первом запуске.
